地図(タップで目印のピン)

ルール: ダーツは全5回。投げる前に難易度(VE×1〜VD×5)を選び、ヒントを見ながら左の入力欄で答えます(国名 → 県名 → 市区町村 → 町名 → 番地の順に選択/入力、難易度に応じて必要な欄が増えます)。地図は目印のピンを立てて推理するのに使えます。当たれば「難易度の倍率 × 早撃ちボーナス」が得点、外れは0点。ヒントが狭い段階で当てるほどボーナスが大きく(7桁段階 ×2 → 最終段階 ×1)、全部外れなら0点、全部VEで最終段階に当てれば5点、全部VDなら25点、全部VDを最速で当てれば最大50点です。
デモ用の簡易地図・模擬ストリートビュー・固定の5地点です。本番は Google Maps Platform(Maps JavaScript / ストリートビュー / Geocoding / Places)を API キーで利用します。 ヒントは20秒ごとに自動で広がり(カウントダウン表示)、早く答えるほど得点が高くなります。
